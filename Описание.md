# проект по глобальному потеплению

## краткое описание

Проект — информационный сайт о глобальном потеплении: раскрывает причины, последствия и простые действия, которые может сделать каждый.
Отдельный блок посвящён правильной утилизации опасных отходов: куда сдавать батарейки и сломанные провода, почему это важно для климата и как переработка снижает выбросы CO₂.
### код
сайт одностраничный и имеет путь "/" - это основная страницы

```
  @app.route('/')
```
### Библиотеки

Flask — это лёгкий веб-фреймворк на языке Python,
который нужен для создания серверной части сайта (бэкенда)

## актуальность
Актуальность такого проекта строится сразу на двух опорах: острой климатической повестке
(последние годы бьют температурные рекорды)и необходимости подавать сложные научные данные
в понятном, наглядном веб-формате.

## цель
Цель проекта — разработать и опубликовать информационный веб-сайт, который в доступной
и наглядной форме знакомит пользователей с причинами, последствиями глобального потепления
и способами его замедления. и способы утилизации разного мусора
